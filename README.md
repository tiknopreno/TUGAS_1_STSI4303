# Tugas 1: Pemrograman Berbasis Objek / Logika Algoritma (TypeScript)

Repitori ini berisi kumpulan penyelesaian tugas pemrograman menggunakan **TypeScript** yang berfokus pada logika dasar pemrograman, manipulasi string/angka berdasarkan NIM (Nomor Induk Mahasiswa), pola segitiga, deret aritmatika, dan pengecekan bilangan prima.

## 📂 Struktur Berkas

- `Mahasiswa.ts` : Berisi definisi kelas `Mahasiswa`, tipe data `DataMahasiswa`, serta implementasi method untuk logika segitiga, deret aritmatika, dan bilangan prima.
- `index.ts` : Berkas utama (`entry point`) untuk menjalankan program dan menguji fungsi-fungsi yang ada di dalam kelas `Mahasiswa`.

---

## 📋 Daftar Soal & Fitur

1. **Soal 1: Membuat Pola Segitiga Berdasarkan NIM**
   - Menghasilkan pola segitiga karakter/angka yang dibentuk berdasarkan digit-digit dari NIM yang diberikan.
2. **Soal 2: Membuat Pola Deret Aritmatika Berdasarkan NIM**
   - Menghasilkan pola deret aritmatika dengan parameter jumlah suku tertentu yang dikombinasikan dengan nilai NIM.
3. **Soal 3: Bilangan Prima Berdasarkan NIM**
   - Menemukan atau memvalidasi deretan bilangan prima yang berkaitan dengan komponen NIM.
